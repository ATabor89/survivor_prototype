# Project Vision: Occult Survivors-Like Game

## Original Inspiration

This project originated from a fascination with the Sacred Abramelin Ritual, an 18-month Solomonic Magick ritual for summoning one's Holy Guardian Angel. This initial interest in occult traditions sparked the idea for a game that would treat various magical systems with depth and authenticity, rather than the usual gamified simplifications.

## Evolution to Current Concept

The project evolved from an extremely complex occult game concept to a more focused Survivors-like game after experiencing:
1. Vampire Survivors (original inspiration for gameplay style)
2. HoloCure: Save the Fans (demonstrated unique character-specific mechanics)

### Key Innovations from HoloCure
- Character-specific starting weapons
- Unique special moves
- Character-specific upgrades
- HoloHouse minigame hub concept

## Current Game Concept

### Core Structure
- Primary Hub: Small village (Stardew Valley-like)
  - Various NPCs and shops
  - Player-owned estate
  - Excavation possibilities
  - Ritual spaces
  - Resource gathering/management

### Expedition System
- Map room for planning expeditions
- Survivors-like gameplay during expeditions
- Resource gathering
- Reality exploration

### Thematic Integration
- All magick systems are treated as real
- Different traditions viewed as different lenses for manipulating reality
- Alchemy serves as the binding system for progression
- "As Above, So Below" principle in world design
- Multiple reality layers (similar to Noita's hidden areas)
- Reality perception changes (similar to Bloodborne's insight system)

### Magnum Opus Progression
1. Nigredo (Blackening)
   - Initial unlocks
   - Reality decomposition
   - Basic manipulation

2. Albedo (Whitening)
   - Secondary unlocks
   - Purification abilities
   - Reality layering

3. Citrinitas (Yellowing)
   - Advanced abilities
   - Solar energies
   - Consciousness expansion

4. Rubedo (Reddening)
   - Final transformation
   - Ultimate unification
   - Reality mastery

### Unique Mechanics
1. Time Dilation
   - Adjustable game speed (0.0-4.0)
   - Affects timer but not gameplay speed
   - Unlocked through rituals

2. Reality Inversion
   - Mirror controls/visuals
   - Affects mirrored realities
   - Integration with gameplay mechanics

3. Estate Management
   - Ritual preparation
   - Run customization
   - Resource management
   - Magical research

4. Loadout System
   - Customizable starting weapons
   - Point allocation system
   - Upgradeable over time
   - Flexible reallocation

## Design Philosophy
- Authentic treatment of occult traditions
- Deep, discoverable systems
- Meaningful progression
- Integration of cosmic horror elements
- Balance between accessibility and depth
- Rewards for exploration and mastery

## Future Expansion Possibilities

- Shared world/setting

- Expanded reality layers
- New magical traditions

## Technical Implementation
- Survivors-like base gameplay
- Automated weapon systems
- Reality layer management
- Time manipulation systems
- Estate/hub management
